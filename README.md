# Chatbots Orchestrator

Chatbots Orchestrator is an admin dashboard for managing and configuring chatbots from one place. It provides a simple interface for creating, customizing, editing, testing, and managing chatbot deployments.

## Features

- **Secure sign-in** — Access the dashboard using an authorized account.
- **Chatbot management** — Browse, search, and manage your chatbots from a single dashboard.
- **Chatbot creation** — Create new chatbots with a name, description, and custom system prompt.
- **Visual customization** — Personalize the chatbot's appearance with configurable colors for the interface, messages, buttons, and other elements.
- **API configuration** — Configure the API key used by each chatbot.
- **Knowledge and media** — Add CSV files as a knowledge source and upload images to customize your chatbot.
- **Editing and configuration** — Update chatbot settings, replace or remove assets, and enable or disable individual chatbots.
- **Embeddable widget** — Generate an embed snippet to integrate a chatbot into a website.
- **Interactive preview** — Test a chatbot in an isolated preview environment before integrating it into a website.
- **Streaming responses** — Display chatbot responses as they are generated.
- **Chatbot deletion** — Remove chatbots through a confirmation step.

## Getting Started

1. Sign in using your authorized account.
2. Browse or search your existing chatbots.
3. Create a new chatbot or open an existing one to edit its settings.
4. Customize its behavior, appearance, and available resources.
5. Preview the chatbot and test its responses.
6. Save your configuration and use the generated embed snippet to integrate the chatbot into your website.

## Chatbot Customization

Each chatbot can be configured independently, including:

- Name and description
- System prompt and behavior
- API credentials
- CSV knowledge files
- Images and other visual assets
- Primary, secondary, and background colors
- Enabled or disabled status

Existing configurations can be updated without recreating the chatbot. API credentials and uploaded assets can be retained, replaced, or removed as needed.

## Demo and Preview

The demo feature lets you preview an embedded chatbot in a dedicated test environment.

- **Render chatbot** — Load a chatbot using its generated embed snippet.
- **Reload chatbot** — Start a fresh embedded session.
- **Clear** — Remove the current preview.

This makes it easy to test the chatbot's appearance and behavior before adding it to a live website.

## Design and User Experience

The dashboard is designed to keep chatbot management straightforward and centralized. Searchable chatbot listings, configurable settings, visual customization, and an interactive preview make it easier to maintain and manage multiple chatbots.
